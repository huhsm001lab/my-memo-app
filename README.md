# 내 메모장 (my-memo-app)

메모, 할 일, 캘린더를 한곳에서 쓰는 개인용 메모장 프로그램입니다.
설치나 서버 없이 브라우저에서 동작하고, 데이터는 내 브라우저(localStorage)에만 저장됩니다.

## 기능

- **메모**: 작성·수정·삭제, 검색, 별(⭐) 중요 표시, 중요 메모 상단 정렬
- **할 일**: 마감일, 완료 체크, 완료 숨기기, 오늘 할 일만 보기
- **캘린더**: 월간 달력, 날짜별 일정 추가, 마감일 있는 할 일 자동 표시
- **연결**: 메모에서 바로 할 일 만들기, 날짜를 누르면 그날의 일정·할 일·메모 모아보기
- **알림**: 앱을 열면 "오늘 마감 할 일" 안내, 브라우저 알림(탭이 열려 있을 때)
- **백업**: 데이터 내보내기 / 가져오기 (JSON 파일)

## 실행 방법

Python이 설치되어 있어야 합니다.

**Windows**: `시작.bat`을 더블클릭하면 서버가 켜지고 브라우저가 열립니다.

**직접 실행**:

```
python -m http.server 5000 --bind 127.0.0.1
```

그다음 브라우저에서 `http://localhost:5000`을 엽니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 뼈대 |
| `style.css` | 모양 (밝은 회색 배경, 흰 카드, 파란 포인트) |
| `app.js` | 동작 코드 (저장, 메모, 할 일, 캘린더, 알림) |
| `icon.svg`, `icon.ico` | 앱 아이콘 |
| `시작.bat` | 로컬 서버 실행 후 브라우저 열기 |

## 참고

- 브라우저 데이터를 지우면 메모도 함께 지워집니다. 설정 탭의 "내보내기"로 백업하세요.
- 주소(포트)가 다르면 다른 사이트로 취급되어 저장된 데이터가 보이지 않습니다.
- 현재 AI 기능은 없습니다. (2단계에서 추가 예정)
